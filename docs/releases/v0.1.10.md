# v0.1.10

从 `feat/authority-permissions` 功能分支发布，基于 `v0.1.9` 同步 Go 与 Common 依赖，继续使用统一的用户—应用权限主体。

## 变更

- 最低 Go 版本升级为 **1.27.4**，依赖固定为 `github.com/IceWhaleTech/ZimaOS-Common/v2 v2.0.0-alpha3`。
- E2E 与 RAG 示例的自有 Go 模块同步声明 Go 1.27.4；第三方依赖的模块声明保持原有要求。
- 继续由已注册应用上下文确定权限主体，以用户当前权限为上限；缺失绑定、未知应用和无效主体拒绝访问，不回退到用户完整权限。新依赖与当前 UserService API 授权契约配套使用。

## 验证与分发

- 被测功能分支提交为 `b8c45c5c888be3b1b5ce83fc5d96c8ecf90ad33e`。其[分支构建](https://github.com/IceWhaleTech/ToolFS/actions/runs/44687498679)已通过，包含 race、真实 FUSE 挂载、只读系统安装包检查及 amd64／arm64 打包。
- 标签发布会重新执行工作流，四项必需 FUSE 场景必须实际通过，跳过不能作为成功。此前分支验证不代替本标签的安装包校验。
- 程序版本由 tag 注入，安装到 `/usr/bin/zimaos-toolfsd`。安装包和校验文件按现有流程上传 OSS，本次不合并 main。
- 本次没有新增 NAS 部署或系统镜像升级验证。
